Esta página demonstra como configurar um produto complementar que será recomendado após o try-on.

Produto Principal: Blusa Vermelha

Produto Complementar: Calça Jeans Premium

Após experimentar virtualmente a blusa, você verá uma recomendação para a calça jeans!

Blusa Vermelha Elegante

R$ 149,90

📝 Como Configurar

Adicione os seguintes data attributes ao elemento omafit-widget-root:

<div
  id="omafit-widget-root"
  data-shop-domain="sua-loja.myshopify.com"
  data-public-id="seu_widget_key"
  data-product-id="id-do-produto"
  data-product-name="Nome do Produto"
  data-product-handle="handle-do-produto"
  data-recommended-product-name="Nome do Produto Complementar"
  data-recommended-product-url="https://sua-loja.com/products/produto-complementar"
>
</div>

🔍 Debug no Console

Abra o console do navegador (F12) para ver os logs detalhados:

  • 🎁 Produto complementar lido do data attribute
  • 🎁 Produto complementar sendo enviado na URL
  • ✅ Produto complementar recebido no WidgetPage
  • 🎁 Produto complementar recebido no TryOnWidget
